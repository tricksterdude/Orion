# Orion

Home Cinema Operations Console

---

## Overview

Orion is a Python application for monitoring and controlling a Docker-based home cinema server.

It provides a single console for viewing service health, diagnostics, Docker information and managing containers without opening Docker Desktop.

---

## Current Features

- Live system dashboard
- Docker container inspection
- HTTP health monitoring
- Response time measurement
- Service diagnostics
- Start containers
- Stop containers
- Restart containers
- View Docker logs

---

## Services Currently Supported

- NZBDAV
- UsenetStreamer
- NZBHydra2
- AIOMetadata
- AIOStreams

---

## Planned Features

- Open Web UI
- Live monitoring
- Automatic refresh
- Storage monitoring
- Backup management
- Docker updates
- Plugin support
- Desktop GUI

---

## Requirements

- Python 3.14+
- Docker Desktop
- Docker Engine
- Requests

Install requirements:

```bash
pip install -r requirements.txt
```

---

## Running Orion

```bash
python main.py
```
